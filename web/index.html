Falling Snake

Un dérivé de Snake en Java : tu joues le canon, et le serpent descend vers toi. Détruis-le avant qu'il n'atteigne ta ligne.

Le premier chargement prend quelques secondes. Clique sur le jeu pour que le clavier fonctionne.

Télécharger le jeu (.jar) Code source sur GitHub

Les touches

← →Déplacer le canon
Espace ou ↑Tirer
P ou ÉchapPause

Les fruits

FruitEffet sur le serpent
BoisObstacle : il descend d'une ligne et repart dans l'autre sens
FraiseIl grandit d'un morceau (une vie de plus)
MyrtilleIl devient invincible pendant 5 secondes
Pièce d'orTous les fruits du plateau sont remplacés

Jouer sur ton ordinateur

Télécharge FallingSnake.jar, puis lance-le avec java -jar FallingSnake.jar (Java 8 ou plus récent est nécessaire).

Fait en Java (Swing). Version web propulsée par CheerpJ.
